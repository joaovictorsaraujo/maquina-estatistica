📖 Fundamentação Matemática e Modelagem Probabilística Completa

1. Espaço Amostral das Paradas dos Rolos

O experimento consiste em 3 rolos independentes com sequência circular canônica R = (A, B, C, D, E) indexada de 0 a 4. Cada parada K_i é sorteada uniformemente com probabilidade P(K_i = k) = 1/5 = 0,20. O espaço amostral das paradas possui |Ω| = 5 × 5 × 5 = 125 elementos equiprováveis:

P(K1 = k1, K2 = k2, K3 = k3) = (1/5) × (1/5) × (1/5) = 1/125 = 0.008 (0.80%)

2. Janela Circular e Linha Central Avaliada

A janela visual é formada por 3 linhas e 3 colunas geradas pelo deslocamento modular:
• Linha Superior: R[K]
• Linha Central (ÚNICA avaliada para pagamento): R[(K + 1) mod 5]
• Linha Inferior: R[(K + 2) mod 5]

Como a transformação k ↦ (k + 1) mod 5 é uma bijeção em Z_5, a linha central possui exatamente a mesma distribuição probabilística que as próprias paradas:

P(Trinca Premiada) = 5 / 125 = 1/25 = 0.04 (4.00%)
P(Sem Trinca / Derrota) = 120 / 125 = 24/25 = 0.96 (96.00%)

3. Esperança Matemática de Lucro Líquido E[X]

Sendo P a variável aleatória do prêmio bruto e a aposta fixa de 1,00 crédito, o lucro líquido é X = P - 1:

E[X] = (1/125)×(+4) + (1/125)×(+9) + (1/125)×(+14) + (1/125)×(+24) + (1/125)×(+49) + (120/125)×(-1)
E[X] = (4 + 9 + 14 + 24 + 49 - 120) / 125 = -20 / 125 = -0.1600 crédito/rodada

4. Retorno Teórico ao Jogador (RTP) e Vantagem da Casa

RTP = E[P] / Aposta = 0.84 / 1.00 = 84.00%
House Edge (Vantagem da Casa) = 100% - 84% = 16.00%

5. Desvio-Padrão Amostral e Teorema Central do Limite

Para calcular o desvio-padrão amostral de N observações independentes, utiliza-se o estimador não-viesado com o divisor de Bessel (N - 1):

s = sqrt( (1 / (N - 1)) * sum( (X_i - X_barra)^2 ) )
SE = s / sqrt(N)
IC 95% = [ X_barra - 1.96 * SE ; X_barra + 1.96 * SE ]
