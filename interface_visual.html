🔄 Experimento 4: A Máquina Lembra do Passado? (Falácia do Apostador)
A Falácia do Apostador (*Monte Carlo Fallacy*): A crença intuitiva e errônea de que "após várias derrotas consecutivas, a máquina está prestes a pagar". O experimento testa se $P(\text{Vitória} \mid \text{3 Derrotas Consecutivas}) = P(\text{Vitória})$.

⚖️ Conclusão Matemática: A diferença entre as taxas é estatisticamente nula e compatível com flutuações amostrais. Cada rodada é um ensaio independente e a máquina não possui memória. A probabilidade de vitória na próxima rodada é sempre exatamente 4,0%, não importa quantas derrotas tenham ocorrido.

📖 Fundamentação Matemática e Modelagem Probabilística

1. Espaço Amostral e Paradas Uniformes

O experimento consiste em 3 rolos independentes com sequência circular $R = (A, B, C, D, E)$ indexada de 0 a 4. Cada parada $K_i$ é sorteada uniformemente com probabilidade $P(K_i = k) = \frac{1}{5} = 0{,}20$. O espaço amostral das paradas possui $|\Omega| = 5 \times 5 \times 5 = 125$ elementos equiprováveis:

P(k1, k2, k3) = (1/5) * (1/5) * (1/5) = 1/125 = 0.008 (0.80%)

2. Janela Circular e Linha Central Avaliada

A janela visual é formada por 3 linhas e 3 colunas:
• Linha Superior: $R[K]$
• Linha Central (ÚNICA avaliada para pagamento): $R[(K + 1) \bmod 5]$
• Linha Inferior: $R[(K + 2) \bmod 5]$

A rodada é premiada se, e somente se, os três símbolos centrais forem idênticos. O número de triplas premiadas é exatamente 5: $\{AAA, BBB, CCC, DDD, EEE\}$.

P(Premio) = 5 / 125 = 1/25 = 0.04 (4.00%)
P(Derrota) = 120 / 125 = 24/25 = 0.96 (96.00%)

3. Esperança Matemática de Lucro Líquido E[X]

Sendo $P$ o prêmio bruto e $X = P - 1$ o lucro líquido do jogador (com aposta fixa de 1 crédito):

E[X] = (1/125)*(+4) + (1/125)*(+9) + (1/125)*(+14) + (1/125)*(+24) + (1/125)*(+49) + (120/125)*(-1)
E[X] = (4 + 9 + 14 + 24 + 49 - 120) / 125 = -20 / 125 = -0.1600 credito/rodada

4. Retorno Teórico ao Jogador (RTP) e Vantagem da Banca

RTP = E[P] / Aposta = 0.84 / 1.00 = 84.00%
Vantagem da Casa (House Edge) = 100% - 84% = 16.00%
